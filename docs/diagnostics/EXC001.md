# EXC001: Exception escapes a no-throw contract

An explicit exception escapes a method whose effective contract is
`[DoesNotThrow]`. Handle the exception, or revise the contract if propagation
is intentional. The message names the namespace-qualified exception type.
An annotated call inside the same method is EXC003, not EXC001. Calls without
an Exceptionable contract are not inferred to throw by this analyzer. Async
and iterator methods are not checked yet, so a synchronous throw inside an
async method does not produce EXC001.

`throw null` and any other compile-time null exception operand are reported
as `System.NullReferenceException`. Throws and calls inside a local function
or lambda are not treated as escaping the enclosing method. User-defined
operators and conversions are checked.

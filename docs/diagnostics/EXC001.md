# EXC001: Exception escapes a no-throw contract

An explicit exception escapes a method whose effective contract is
`[DoesNotThrow]`. Handle the exception, or revise the contract if propagation
is intentional. Calls without an Exceptionable contract are not inferred to
throw by this analyzer. Async and iterator methods are not checked yet, so a
synchronous throw inside an async method does not produce EXC001.

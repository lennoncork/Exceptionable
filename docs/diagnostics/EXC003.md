# EXC003: Annotated call may throw an unhandled exception

A call, constructor invocation, property or event access, user-defined
operator, or user-defined conversion has a known `[Throws]` contract that is
not covered by a catch or the caller's `[Throws]` contract. Declare a
compatible exception or handle it.

A constructor that lets `ArgumentNullException` escape has that contract even
when the source has no `[Throws]` attribute. The caller must catch it or
declare it. The caller's own caller does not inherit the contract. A
constructor that only chains with `: this()` or `: base()` is checked at that
chain, and is not given the contract itself. EXC007 suppresses this implicit
contract for a nullable-redundant guard. An ordinary method that throws
`ArgumentNullException` does not gain a contract, so its caller is not EXC003.

The same check includes field and property initializers, `this()` and
`base()` constructor calls, synchronous `foreach` pattern methods
(`GetEnumerator`, `MoveNext`, `Current`, and `Dispose`), synchronous `using`
`Dispose`, and deconstruction assignments. `base` access is bound to the
selected member. A property or event `[Throws]` contract applies to its
accessors unless an accessor declares its own contract. `nameof` is not a
call. `GetEnumerator` is checked even though its return type is otherwise
treated as deferred, because `foreach` invokes it immediately.

An annotated interface member's contract is honored when the call is
statically made through an interface-typed value. Each interface call uses
that interface member's contract. A derived interface member that redeclares
a base member and does not declare its own contract keeps the base contract.
Several inherited contracts intersect, and an empty intersection is
`[DoesNotThrow]`. The message names each exception with its namespace.
Inside a source implementation, calls and throws use the intersection of
that method's contract and every interface contract it implements. A class-level `[Throws]` also applies to accessors,
including auto-property getters and setters. Diagnostic text names those
accessors as getters, setters, or event add and remove accessors, and names
constructors as constructors.

Open virtual, abstract, and unsealed override calls are not analyzed. `base`
calls are analyzed as the selected member. Sealed methods and methods on
sealed types are analyzed as the selected method.
Async and iterator bodies and recognized deferred call sites are skipped:
`[Throws]` does not yet describe exceptions observed when awaiting a `Task`
or enumerating an iterator, and a synchronous throw inside an async method is
not reported either. Calls returning `Task`, `ValueTask`, `IEnumerable`,
`IEnumerator`, `IAsyncEnumerable`, or `IAsyncEnumerator` are also skipped
because the analyzer does not distinguish eager from deferred implementations
of those return types.

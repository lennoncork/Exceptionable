# EXC003: Annotated call may throw an unhandled exception

A call, constructor invocation, or property access has a known `[Throws]`
contract that is not covered by a catch or the caller's `[Throws]` contract.
Declare a compatible exception or handle it.

An annotated interface member's contract is honored when the call is
statically made through an interface-typed value. Each interface call uses
that interface member's contract; a source implementation is separately
checked against every interface contract it implements.

General class virtual/override dispatch is not analyzed. Async and iterator
bodies and recognized deferred call sites are skipped: `[Throws]` does not yet
describe exceptions observed when awaiting a `Task` or enumerating an iterator.
Calls returning `Task`, `ValueTask`, `IEnumerable`, `IEnumerator`,
`IAsyncEnumerable`, or `IAsyncEnumerator` are also skipped because the
analyzer does not distinguish eager from deferred implementations of those
return types.

# EXC004: Invalid exception name in `[Throws]`

The string supplied to `[Throws]` must identify exactly one exception type.
Use a fully qualified metadata name such as `System.IO.IOException` to avoid
ambiguity. A leading `global::` is accepted and ignored. Nested types accept
the metadata form (`N.Outer+NestedException`) or the dotted C# form
(`N.Outer.NestedException`). A short name resolves when exactly one exception
type has that name; another type with the same name that does not derive
from `System.Exception` is ignored. When more than one exception type matches,
EXC004 says the name is ambiguous. Types that do not derive from
`System.Exception`, and names that match nothing, are invalid.

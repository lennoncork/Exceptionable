# EXC004: Invalid exception name in `[Throws]`

The string supplied to `[Throws]` must identify exactly one exception type.
Use a fully qualified metadata name such as `System.IO.IOException` to avoid
ambiguity. Nested types accept that metadata form (`N.Outer+NestedException`)
or the dotted C# form (`N.Outer.NestedException`). A short name resolves when
exactly one exception type has that name; another type with the same name
that does not derive from `System.Exception` is ignored. Types that do not
derive from `System.Exception` are invalid.

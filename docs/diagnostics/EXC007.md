# EXC007: Unnecessary ArgumentNullException

A constructor throws `ArgumentNullException` for a non-nullable reference
parameter while nullable annotations are enabled. The analyzer assumes callers
honor that annotation and will not pass null. Remove the throw.

The same warning applies when the throw does not name a parameter and every
reference-type parameter of the constructor is a non-nullable reference.
`string?` and `[AllowNull]` parameters are not covered: the caller is allowed
to pass null, so the constructor keeps an implicit
`[Throws(typeof(ArgumentNullException))]` contract and callers are checked
with EXC003.

Nullable annotations are not a runtime null check. Suppress EXC007 where the
defensive guard should stay. The warning is not also EXC002. A
`[DoesNotThrow]` constructor still reports EXC001 for the escaping throw.

`ArgumentNullException.ThrowIfNull` is an ordinary method call. It does not
produce EXC007 and does not create an implicit contract.

# EXC008: Declared exception does not escape

A `[Throws]` type is no longer produced by the member. Remove it from the
attribute, or restore a reachable throw or known call that produces that
type or a derived type. The message names the namespace-qualified exception
type and the member.

EXC008 is reported only when the member produces some other known escaping
exception. A new or changed throw is still EXC002. A `[Throws]` attribute on
a member with no known escaping throw or call stays as the published
contract and is not EXC008.

A declared base type is satisfied by a derived throw or by a call whose
contract includes a derived type. A caught or unreachable throw does not
keep the declaration. `[DoesNotThrow]` is EXC001 when an exception escapes,
not EXC008.
